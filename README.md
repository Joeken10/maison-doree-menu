Safari Restaurant Menu is a modern digital restaurant menu built with React. The menu presents a premium dining experience through visually rich food photography, categorized sections, detailed dish descriptions, ingredient information, and pricing.

The menu is organized into a magazine/booklet-style layout featuring:

Soups & Starters
Salads & Wok Dishes
Seafood
Kenyan Specialities
Grills
Burgers & Sandwiches
Pizza & Pasta
Desserts
Features
Interactive Menu Layout
Multi-page menu structure
Category-based organization
Elegant restaurant-style presentation
Responsive design for desktop, tablet, and mobile devices
Rich Food Content

Each menu item includes:

Dish name
Short subtitle
Price (KES)
Food image
Detailed description
Ingredient list
